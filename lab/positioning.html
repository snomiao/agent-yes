Naming & positioning

Keep the name. Change the lede.

agent-yes (domain, ay/cy binaries, the green ✓) is a brand asset — don't reset it. The real problem a first-time user hit isn't the name; it's that the biggest value is buried under "auto-yes wrapper" framing. Lead instead with the part that's genuinely yours:

Run any AI coding agent unattended — then watch and steer it from your phone over one end-to-end-encrypted link. ↑ the one-liner that should be the first sentence everywhere.

01Where you actually sit

You're not another agent in a crowded field — you're the layer that runs, watches and steers any of them. Position above the agents, not beside them.

You — laptop & phone
watch · send input · spawn · attach — from anywhere
▲ one E2E-encrypted link (zero-knowledge relay)
agent-yes — the harness / remote console
auto-answers routine prompts · ay serve live console · cy ls/tail/send/attach
▲ wraps the PTY of
the agents (crowded, commoditized)
Claude Code · Codex · OpenCode · Goose · Aider · Cline · Gemini CLI · …
  • Don't compete with the agents — ride all of them. The clean, less-crowded slot is "harness / control-plane." (There's even an awesome-cli-coding-agents directory whose category is exactly "harnesses that orchestrate them" — get listed.)
  • Vs unattended orchestrators (Aeon, Kodo, Agentic) — those are headless CI/cron. Your wedge is interactive remote supervision: the encrypted console + phone steering. Nobody else leads with that.
  • "auto-yes" is contested & commoditized — there's already an npm auto-yes (ay) PTY auto-responder, plus your own older claude-yes/yes-claude. The console is yours alone → lead with it.

02The name — keep agent-yes, but…

✓ Why keep it

  • Descriptive of the original wedge; memorable; the green ✓ reinforces it.
  • ay / cy / *-yes aliases are genuinely good and instantly understandable.
  • Domain + binaries + brand are already established — a rename is pure cost.

⚠ Why reposition

  • Undersells the console / share / remote-steer story.
  • "yes" reads as reckless approval — awkward next to your own prompt-injection warning.
  • "agent yes" is SEO-muddy and sounds like a behavior patch, not infrastructure.
If you ever did rename (not recommended now) — candidates

Leaning to the control-surface story: AgentDeck, AgentRelay, AgentWire (encrypted connection vibe). Others brainstormed: AgentLink, Teleagent, Yesrun, AyeAye, Overseer — most are collision-heavy or carry baggage. None justify resetting the brand.

04The 30-second first-run (lead with the magic)

Three commands, then the phone moment — not a feature list.

# install
curl https://agent-yes.com/setup.sh | sh

# run an agent — routine confirmations & retries handled, so it keeps going
ay claude

# expose it: prints ONE end-to-end-encrypted link
ay serve --share   # → open on your phone: watch · send input · spawn · attach

The 30-second story: "Start Claude/Codex/Gemini through ay; it auto-handles routine prompts so the session keeps moving. Run ay serve --share for an encrypted console link — open it anywhere to monitor, steer, or attach."
